# 项目计划：英文短篇全自动生产线

- 文档版本：v3.0（2026-08-14，v1 正式版交付后更新）
- 状态：**v1 正式版已交付**（所有 P0-P2 里程碑完成）

---

## 1. 项目背景与目标

### 1.1 背景与演进

- **InkOS 评估结论（已定稿）**：InkOS 实测硬伤——字数规则内部打架（目标 650 实际 336-608 波动）、英文 AI 味把控差、英文产出是黑盒。InkOS **不参与生产**，仅作审计思路参考。
- **自研写作引擎（P0）已完成**：大纲→world bible→分章，字数硬校验达标率 100%。
- **写作模型已定稿**：GPT-5.5 分段续写为主（naturalness 5），Gemini 3.1-pro（需代理）/ deepseek（兜底）多模型备份。
- **质量体系已定稿**：质量门槛（naturalness ≥4）+ 质检拦截（native ≥4 / engagement ≥3）+ 书内自学习闭环。

### 1.2 目标

构建一条面向海外英文市场、低人力干预的短篇小说批量生产线。

- 业务目标：稳定批量产出 12 章英文短篇，日产能可配置
- 技术目标：① 自研英文写作引擎 ✅ → ② 选品雷达 ✅ → ③ 质检 ✅ → ④ 包装调度 ✅
- 质量底线：所有结论区分验证层级，不做假数据；英文质量用「母语级模型盲评」量化

### 1.3 里程碑状态（v1 交付后）

| 里程碑 | 内容 | 状态 |
|---|---|---|
| M0 | 管线三件套 + 榜单抓取验证 | ✅ 完成 |
| M1 | P0 写作引擎（自研 + 字数硬校验）| ✅ 完成（100% 达标）|
| M2 | 选品雷达（RoyalRoad 三榜 + 空位量化）| ✅ 完成 |
| M3 | 质检（native-check 母语级审稿）| ✅ 完成（GPT/GLM 5/5）|
| M4 | 包装调度（packager + orchestrator + dashboard）| ✅ 完成 |
| M5 | 反馈闭环（销量回流）| ⬜ 暂缓（依赖营销部门）|

### 1.4 非目标（v1 明确不做）

| 事项 | 原因 |
|---|---|
| 自训大模型（fine-tune）| 需云 GPU + 高质量语料，成本周期不可控 |
| 长篇自动连载 | 依赖反馈数据，与反馈闭环一起暂缓 |
| 发布动作自动化 | 上传平台需人工执行，只产出文件包 |
| 反馈 / 决策 / 复盘闭环 | 暂缓，依赖营销部门对接数据 |

## 2. 当前阶段工作

v1 已交付，进入试运行期：

1. **量产级验证**：一次跑 10+ 部，统计 naturalness 分布（当前为单章/3 章级验证）

3. **通知渠道**：流程中断/质检不过时通知
4. **反馈闭环对接**：销量数据回流，指导选品（M5）
