# 使用手册（面向使用者）

> 版本：v1.0 | 更新：2026-08-14
> 目标读者：使用生产线的人（不需要懂技术）

---

## 1. 这是什么

一条**全自动英文短篇小说生产线**。你只需要：打开页面 → 点开始 → 等结果 → 下载成品。

选题、写作、质检、包装全部自动完成，不需要你提供任何故事方向。

---

## 2. 启动看板（每天只需一次）

```powershell
cd /d E:\novel pro
py -3 dashboard.py
```

浏览器打开 **http://localhost:8900**（建议固定到书签）。

### 2.1 第一次使用：配置 key

首次打开会弹出**配置 API Key** 界面，填你自己的 key：

| 字段 | 必填 | 说明 |
|---|---|---|
| GPT Key（写作+审查）| 是 | 从 GPT 中转服务商获取，`sk-` 开头 |
| Gemini Key（可选）| 否 | 从 Google AI Studio 获取，`AQ.` 开头，审查兑底用 |
| 代理地址（可选）| 否 | 默认 `http://127.0.0.1:7897`（Clash）|

> key **只保存在本机** `keys.local.json`，不会上传到任何地方，也不会进代码仓库。
> 想换 key：删除 `E:\novel pro\keys.local.json`，刷新页面重新填。

## 3. 开始 / 暂停生产

页面顶部是**生产控制**：

```
▶ 开始全自动生产      ⏸ 暂停生产
```

| 操作 | 做什么 |
|---|---|
| **开始** | 自动扒取热门榜单 → 自动选最佳题材 → 自动写 12 章 → 质检 → 打包。全程无需人工 |
| **暂停** | 立即停止当前正在跑的生产（已写好的章节保留，可继续用） |

> 提示：写一部 12 章约 40-60 分钟。点开始后可以关页面，后台继续跑，回来刷新就能看到结果。

---

## 4. 看进度

页面最上方是**当前进度卡**，显示：雷达选品 → 采纳推荐 → 写作中 → 质检中 → 包装中 → 完成。

页面每 15 秒自动刷新，也可以手动点"刷新"。

---

## 5. 下载成品

"产物清单"卡片里，每个成品后面有 ⬇ 按钮：

- **⬇ xxx.epub**：成品电子书（可以直接投放到平台）
- **⬇ 发布清单**：这本书的元信息（标题/简介/标签）

点一下就下载到浏览器。

---

## 6. 调整质量标准（可选）

"质量阈值"卡片可以调三个数字，保存后对**后续**生产生效：

| 参数 | 默认 | 说明 |
|---|---|---|
| 质量门槛 naturalness | 4 | 每章最低自然度（越高要求越严）|
| 质检地道性 native | 4 | 英文母语级流畅度要求 |
| 质检精彩度 engagement | 3 | 故事吸引力要求 |

**调高** = 质量更稳但更慢（重写更多）；**调低** = 更快但质量波动。

> 一般不用动。想更快出量就调低 1，想更稳就保持默认。

---

## 7. 高级功能（一般不用）

"高级：自定义方向生产"：跳过自动选品，直接按你输入的方向写一部。

> 例：`US-market domestic suspense: a forensic accountant discovers her husband faked his own death`
> 只有你想定向生产特定题材时才用。

---

## 8. 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 点开始后进度一直"雷达选品" | 正在抓榜单，正常 | 等 1-3 分钟 |
| 进度卡不动了 | 模型中转偶发波动 | 点"刷新"，等 5 分钟，若仍不动点"暂停"再"开始" |
| 产物清单是空的 | 还没跑完一部 | 等完成后再看 |
| 下载的 EPUB 打不开 | 阅读器不支持 | 换标准阅读器（微信读书/Calibre）|
| 想换题材方向 | — | 用"高级：自定义方向生产" |
