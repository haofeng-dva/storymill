## 1. 发布说明 v1.0.0

### 1.1 本版新增

1. **全自动生产闭环**：选品雷达 → 方向采纳 → 写作 → 质检 → 包装 → 调度，一条命令
2. **写作模型多后端**：Gemini 3.1-pro / GPT-5.5 / deepseek 系列，profiles 自动路由
3. **GPT 分段续写**：避开中转 60 秒超时，naturalness 可达 5
4. **质量门槛**：每章盲评 naturalness <4 自动带反馈重写
5. **质检拦截**：地道性 ≥4 / 精彩度 ≥3，不过 exit 2 不包装
6. **书内自学习**：每本书独立 lessons.json，失败反馈回灌，越写越好
7. **三模型检测降级链**：GPT → GLM → Gemini，自动切换
8. **Web 看板**：http://localhost:8900，进度/推荐/产物/开关/触发

### 1.2 本版修复

1. GPT 审稿 system → developer 角色（新版 Responses API 兼容）
2. Gemini 长输出 thinking 泄漏 / 截断（改用分段或 minimal 包）
3. 字数硬校验达标率 100%（大纲 beat 充足化）
4. 质检不拦截问题（新增 exit code + orchestrator 拦截）

## 2. 部署配置

### 2.1 环境要求

| 项 | 要求 |
|---|---|
| Python | 3.13（标准库为主，无第三方依赖）|
| 网络 | GPT 中转直连；Gemini 需代理（Clash 7897）|
| 磁盘 | 产出约几 MB/部（文本）|

### 2.2 密钥配置（.env）

```
# GPT 中转（写作 + 审稿主力，直连）
OPENAI_RELAY_KEY=sk-...
OPENAI_RELAY_BASE=https://api.aicodec.eu.cc
OPENAI_RELAY_MODEL=gpt-5.5

# Gemini（写作/审稿备选，需代理）
GEMINI_API_KEY=AQ....
GEMINI_MODEL=gemini-3.1-pro-preview
GEMINI_PROXY=http://127.0.0.1:7897
```

> 注：ARK_API_KEY（火山方舟）在系统环境变量，不在 .env。

### 2.3 模型配置（config.json）

```json
{
  "llm": {
    "models": {
      "writer": "gpt-5.5",              // 写作（GPT 分段续写）
      "outline": "gpt-5.5",             // 大纲
      "reviewer": "glm-5-2-260617",     // 审稿兜底
      "cn_summary": "deepseek-v4-flash-260425",
      "radar": "deepseek-v4-flash-260425"
    }
  },
  "writing": {
    "default_chapters": 12,
    "default_words": 700,
    "word_min": 620,
    "word_max": 780,
    "max_rewrite": 3,
    "temperature": 0.85
  }
}
```

**模型切换**：
- 用 GPT：writer/outline = gpt-5.5（当前默认，直连）
- 用 Gemini：writer/outline = gemini-3.1-pro-preview（需开 Clash）
- 用火山方舟：writer/outline = deepseek-v4-flash-260425（质量较低，naturalness 2-3）

### 2.4 调度配置（orchestrator.json）

```json
{
  "switches": {
    "new_short_enabled": true,   // 总开关
    "serial_enabled": true,
    "auto_replace_enabled": false
  },
  "limits": {
    "max_stories_per_day": 2,    // 日产量上限
    "daily_token_budget": 500000,
    "approx_tokens_per_story": 150000
  }
}
```

### 2.5 部署步骤（从零）

```powershell
# 1. 确认 Python 3.13
py -3 --version

# 2. 配置 .env（填密钥）、config.json（选模型）、orchestrator.json（限流）

# 3. 冒烟测试
py -3 orchestrator.py --dry-run        # 验证命令拼接
py -3 engine.py --direction "test suspense story" --chapters 1 --words 700 --story-id smoke_test --quality-gate
py -3 native_check.py --story-id smoke_test --sample 1   # exit 0 且 provider 正常

# 4. 启动看板
py -3 dashboard.py

# 5. 计划任务（可选）：定时触发 orchestrator.py --cycle
```

### 2.6 验收标准

| 检查项 | 通过标准 |
|---|---|
| 冒烟测试 | 一章写出，quality ≥4，质检 exit 0 |
| 全流程 | --cycle 跑通，产物有 EPUB |
| 隔离 | 删书目录 lessons.json 不影响其他书和全局 |
| 降级 | GPT 断时自动用 GLM，日志 provider 变化 |
